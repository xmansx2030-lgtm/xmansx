# التحقق من البحث عن ولي الأمر

التاريخ: 2026-10-09. أساس العمل `f50ac7b`، الفرع المحلي `codex/family-search-20261009`.

كان تبويب `/parent-management?tab=families` يعرض الأسر بترقيم الصفحات دون حقل بحث.
أضيف حقل بحث باسم ولي الأمر المدرسي أو الاسم المعتمد في دعوته أو اسم أحد الأبناء
أو رقم الجوال. البحث خادمي في جميع أسر المدرسة، قبل ترقيم الصفحات، وتظهر جميع
أبناء الأسرة عند مطابقة أحدهم. يدعم أجزاء الأسماء والأرقام العربية وصيغ الجوال
المحلية والدولية واختلاف همزات الألف والتشكيل، دون تعديل البيانات الأصلية.

الواجهة تطبق البحث بعد توقف الكتابة 350ms، تعود إلى الصفحة الأولى وتمسح التحديد
السابق. يظهر عدد الأسر المطابقة ورسالة واضحة للنتائج الفارغة وزر مسح البحث.
الموافقات وإرسال الدعوات والتفعيل لا تتغير، ولا توجد هجرة قاعدة بيانات.

## حالة الموقع الحي

فتح الرابط المحدد في Chrome أعاد أولاً إلى `/login`، ثم سجل المستخدم الدخول.
فُتح التبويب بحساب مدير المدرسة: **796 أسرة مقترحة، 25 بطاقة في الصفحة الأولى**.
فحص DOM الحي أكد صفر حقول بحث وصفر حقول نص؛ التنقل المتاح بين صفحات فقط.
أُبقي التبويب المطلوب مفتوحاً. التعديل محلي في شجرة العمل المعزولة؛ لم يُرفع أو يُدمج أو يُنشر.
لم تُرسل دعوات إنتاج ولم تُعدّل بيانات مدرسة فعلية.
