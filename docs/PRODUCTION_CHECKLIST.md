# قائمة جاهزية الإنتاج

لا تعتمد أي خانة من الذاكرة أو من نجاح بيئة محلية؛ احفظ رابط الدليل أو ناتج الأمر
بجوار سجل الإصدار.

## قبل الإصدار

- [ ] فرع `main` يشير إلى SHA المطلوب ولا توجد تغييرات مشروع غير ملتزمة.
- [ ] نجحت وظائف CI: Backend وFrontend والجسر وGitleaks وبوابة Playwright الإنتاجية.
- [ ] نشرت صورا Backend وFrontend من SHA واحد، وسجلت digests الناتجة.
- [ ] ملف أسرار الخادم خارج Git وصلاحياته مقيدة، ولا يحوي قيما تجريبية.
- [ ] `DEBUG=False` وHTTPS وHSTS وSecure cookies مفعلة، والنطاقات/origins صريحة.
- [ ] مفاتيح تشفير الهوية محفوظة في مدير أسرار مع نسخة استعادة منفصلة.
- [ ] R2 مفعل بحاويتين خاصتين منفصلتين: ملفات التطبيق والنسخ الاحتياطية.
- [ ] النسخ اليومي مفعل، وآخر نسخة بعيدة ناجحة وأصغر من 26 ساعة.
- [ ] Sentry وuptime monitoring مضبوطتان على البيئة والإصدار الصحيحين.

## النشر

- [ ] شغل `scripts/deploy_release.sh` بصور تحمل SHA الكامل نفسه.
- [ ] حفظ ناتج migration و`check --deploy` ومعرف النسخة السابقة.
- [ ] الحيوية `/api/v1/health/live/` ترجع 200.
- [ ] الجاهزية `/api/v1/health/ready/` ترجع 200 وPostgreSQL/Redis كلاهما `ok`.
- [ ] backend وworker وbeat وfrontend وقاعدة البيانات وRedis بحالة سليمة.

## التحقق الوظيفي بعد النشر

- [ ] مدير مدرسة: دخول، لوحة الإدارة، الإعدادات، واستيراد صغير آمن.
- [ ] معلم: اختيار المدرسة، تحضير حصة، وإعادة فتح الجلسة.
- [ ] وكيل: المتابعة والتحليلات والأعذار والإنذارات والإحالة.
- [ ] مرشد: استلام إحالة، جلسة، خطة، وطلب متابعة معلم.
- [ ] مشرف منصة: الخطط والاشتراكات فقط، بلا وصول إلى بيانات الطلاب.
- [ ] تنزيل مستند خاص يعمل للمصرح له ويرجع 404 لمستخدم مدرسة أخرى.
- [ ] Manifest وservice worker والتحديث وعدم كشف بيانات جلسة بعد logout/offline سليمة.

## المراقبة والتراجع

- [ ] ظهر الإصدار في Sentry ونفذت رسالة تحقق غير محتوية على بيانات شخصية.
- [ ] لا ارتفاع غير معتاد في 5xx أو زمن الاستجابة أو طوابير Celery بعد النشر.
- [ ] إن فشل health/readiness فلا يوجه المرور إلى النسخة الجديدة.
- [ ] التراجع التطبيقي يستخدم صور الإصدار السابق فقط إن كان schema متوافقا.
- [ ] التراجع البياني يتم باستعادة نسخة ما قبل النشر في قاعدة جديدة ثم التحقق والتحويل؛
      لا تنفذ migrations عكسية عمياء على قاعدة الإنتاج.

[BACKUP_RESTORE.md](BACKUP_RESTORE.md) للاستعادة، و[OBSERVABILITY.md](OBSERVABILITY.md)
لعقود الصحة والتنبيهات.
