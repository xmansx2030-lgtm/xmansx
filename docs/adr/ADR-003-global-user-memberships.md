# ADR-003: مستخدم عالمي + عضويات مدرسية

- **الحالة:** مقبول — 2026-08-18
- **السياق:** المعلم قد يعمل في أكثر من مدرسة؛ إنشاء حساب لكل مدرسة يكرر الهوية ويكسر تسجيل الدخول بالجوال العالمي.
- **القرار:** `User` عالمي فريد برقم الجوال المطبّع (`+9665XXXXXXXX`). الربط بالمدارس عبر `SchoolMembership` (unique: user+school، مع `is_active`)، والأدوار عبر `MembershipRole` (عدة أدوار للعضوية الواحدة). `PLATFORM_ADMIN` سمة على User خارج نظام العضويات.
- **التبعات:** استيراد المعلمين يعيد استخدام الحسابات الموجودة؛ تبديل المدرسة تغيير `active_school` في الجلسة بعد التحقق من العضوية؛ تعطيل معلم في مدرسة لا يمس حساباته في مدارس أخرى.
