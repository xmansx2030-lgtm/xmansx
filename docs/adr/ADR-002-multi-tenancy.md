# ADR-002: عزل المستأجرين بـ school_id في قاعدة واحدة

- **الحالة:** مقبول — 2026-08-18
- **السياق:** بدائل العزل: قاعدة لكل مدرسة، Schema لكل مدرسة، أو صفوف مشتركة بمفتاح مستأجر. مئات المدارس المتوقعة تجعل إدارة قواعد/Schemas منفصلة مكلفة (Migrations × N).
- **القرار:** Shared DB / Shared Schema؛ كل جدول مدرسي يحمل `school_id` (FK إلزامي، غير قابل لـ NULL). الإنفاذ بأربع طبقات: Middleware يحدد `request.school` من الجلسة بعد التحقق من العضوية، `SchoolScopedManager` يمنع الاستعلام غير المحدود افتراضيًا، Base ViewSet يفلتر مركزيًا، واختبارات عزل إلزامية لكل Endpoint.
- **التبعات:** Migrations واحدة للجميع وتقارير منصة سهلة؛ المخاطرة الأساسية IDOR/تسرب عبر استعلام غير محكوم — تُدار بالطبقات الأربع وبمنع `Model.objects.all()` في مسارات المدارس (مراجعة + lint rule لاحقًا). RLS في PostgreSQL خيار تحصين مستقبلي غير معتمد في MVP.
