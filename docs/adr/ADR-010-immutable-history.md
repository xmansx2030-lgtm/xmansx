# ADR-010: التاريخ غير قابل للحذف — Snapshots وسجلات تغيير

- **الحالة:** مقبول — 2026-08-18
- **السياق:** الإنذارات والمستندات وثائق رسمية تُطبع وتُسلّم؛ إعادة توليدها من البيانات الحالية بعد تغير الغياب تزوير فعلي للتاريخ.
- **القرار:**
  - `StudentWarning` يخزن Snapshot لعدادات الطالب وقت الإصدار (`absence_days_at_issue`, `late_count_at_issue`, …) ولا يُعاد حسابه أبدًا.
  - `GeneratedDocument` يخزن النسخة الناتجة (ملف PDF في Object Storage) + Snapshot للبيانات المولدة منها.
  - تحويل الغياب إلى بعذر لا يحذف الحالة الأصلية: يبقى السجل مع `original_status` و`current_status` وسجل تغيير (`changed_by`, `changed_at`, `reason`).
  - استبدال ملف نور الجديد لا يحذف تاريخ الطالب — الانتقال بين الفصول عبر `StudentEnrollment` (إغلاق قيد وفتح آخر)، والطلاب المفقودون من الملف يُعلّمون غير نشطين لا يُحذفون.
  - `AuditLog` append-only — لا حذف ولا تعديل.
- **التبعات:** نمو بيانات مقبول مقابل نزاهة قانونية/إدارية كاملة وقابلية تدقيق.
