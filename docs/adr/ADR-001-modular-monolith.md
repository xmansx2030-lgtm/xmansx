# ADR-001: Modular Monolith بدل Microservices

- **الحالة:** مقبول — 2026-08-18
- **السياق:** منصة SaaS جديدة بفريق صغير ونطاق MVP واسع (18+ وحدة وظيفية). Microservices تضيف كلفة تشغيل وشبكة وتناسق بيانات لا يبررها الحجم الحالي.
- **القرار:** مشروع Django واحد وقاعدة PostgreSQL واحدة، مقسم إلى Apps بحدود صارمة (Service Layer + Selectors، ممنوع الاستيراد العابر المباشر للـ Models في طبقات العرض).
- **التبعات:** نشر أبسط، Transactions حقيقية عبر الوحدات، اختبارات أسهل. الانضباط في الحدود مسؤوليتنا (مراجعة كود + قواعد استيراد). إذا احتجنا فصل خدمة مستقبلًا (مثل توليد PDF) تكون الحدود جاهزة.
